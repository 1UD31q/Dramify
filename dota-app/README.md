# DotaHelperr

Десктопное приложение (Electron + React) со статистикой игроков Dota 2 на основе [OpenDota API](https://docs.opendota.com/).

Профиль игрока: ранг, победы/поражения и винрейт, последние матчи, любимые герои, с кем играет.

## Запуск на Windows

Нужен [Node.js](https://nodejs.org) LTS.

```bash
npm install
npm run dev     # режим разработки с горячей перезагрузкой
npm run dist    # собрать установщик .exe в папку release/
```
